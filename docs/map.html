Where My Research Takes Me

Field sites, watersheds, conferences, and institutions on one map.

As an open-source GIS enthusiast, I thought it would be fun to create an interactive map of all the places I have conducted research, as well as all of the places I have been fortunate enough to travel to for conferences, workshops, and colloquia. Use the buttons on the left to jump between regions, and click a field site to read about the project behind it.
